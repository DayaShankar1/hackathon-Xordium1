# 3-Minute Judge Demo Script

## Opening (20 seconds)

"Students currently use separate groups, notice boards and informal channels for everyday campus needs. CampusSphere brings five useful campus services into one place."

## Demo flow (2 minutes)

1. **Dashboard:** Show the five modules and explain the single sign-in.
2. **Lost & Found:** Create a sample lost-item report and show it appearing in the feed.
3. **Resource Hub:** Find a sample subject resource and download it.
4. **ClubConnect:** Open an event and register.
5. **Marketplace:** Show a student listing and its condition/price.
6. **CampusFix:** Submit a sample Wi-Fi issue, then switch to the admin account and update its status.

## Impact (25 seconds)

Show one measured result from actual testing. Example measurement approach:
- Ask 3–5 students to complete a task using the current method.
- Time the same task using CampusSphere.
- Compare median completion times.
- State sample size and limitations.

Do not invent a percentage saved. If you have not measured it, say that impact measurement is planned.

## Closing (15 seconds)

"CampusSphere is not five separate apps. It is one connected campus experience, built around the tasks students already need to complete."

## Backup plan

If live network access fails:
- Keep a pre-seeded demo account.
- Have screenshots or a short local recording ready as backup only.
- Be transparent if a live integration is unavailable; do not claim a recorded demo is live.
